### The Backend "Roadmap" for OOP

1. Classes & Constructors: Moving your RAM array logic into a Database class.

2. Private Fields: Protecting sensitive data like we just did.

3. The Service Pattern: Creating classes that only handle business logic (e.g., UserService.js).

4. The Repository Pattern: Creating classes that only handle data storage (e.g., UserRepository.js).

5. Dependency Injection: Passing one class into another (e.g., passing the Database class into the Server class).
