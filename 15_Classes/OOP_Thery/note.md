OOP (Object-Oriented Programming)

how you organize the logic of your server


### ============================================================
1. Encapsulation (The "Black Box")
    Keeping the data and the logic that changes it in one place.

2. Abstraction (The "Interface")
    Hiding complex logic behind a simple method name.

3. Inheritance (The "Hierarchy")
    Creating a generic class and extending it.

4. Polymorphism (The "Shape-Shifter")
    Using the same method name for different types of objects.
