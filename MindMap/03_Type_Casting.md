# Type Casting

- The process of Convert Type

## Type Conversion

- When you intentionally Convert Type
- `Number("3.14"), String(33.33)`

## Type Coercion

- when JavaScript automatically Converts Type
- `+ - \* / > < ==`

## Falsy Rule `null undefined NaN "" 0 -0 0n -0n`

1. `null`
2. `undefined`
3. `NaN`
4. `""` Empty String
5. `0` Number Zero
6. `-0` Number Negative Zero
7. `0` BigInt Zero
8. `-0` BigInt Negative Zero
