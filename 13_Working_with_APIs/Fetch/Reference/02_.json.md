```js
const response = await fetch("http://localhost:3000/users");
const data = await response.json();
console.log(data);
// [
//   { id: 1, name: 'Joel', role: 'Admin' },
//   { id: 2, name: 'Arch_User', role: 'Dev' }
// ]
```

### ============================================================
response.json(): The Parsed Data

When you call .json(), 
you are telling Node.js (or the browser) 
to "Read the stream of text coming from the server 
and turn it into a JavaScript Array/Object."

What it contains: The actual users array from your RAM.

The Console Output: 
    You will see the actual data: [{ id: 1, name: 'Joel' ... }].
