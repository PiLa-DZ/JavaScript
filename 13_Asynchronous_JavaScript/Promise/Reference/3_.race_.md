2. The "Fastest Mirror" Strategy

Imagine you are downloading a large file on Arch. 
You have three different mirrors (US, EU, ASIA). 
You don't care which one you use; 
you just want the one with the lowest latency.

```js
Promise.race([
  fetchFromMirror("US"),
  fetchFromMirror("EU"),
  fetchFromMirror("ASIA")
])
  .then((data) => console.log("Downloaded from fastest source!"))
  .catch((err) => console.error("The fastest mirror actually failed."));
```
